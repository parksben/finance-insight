# 澜投研·每日学习摘要 2026-03-19

## 今日核心学习

### 1. HALO因子的动态权重评估法
高盛提出的HALO策略（偏好重资产、规避轻资产）在ETF实战中效果分化。对轻资产（游戏、互联网）冲击明显，对重资产更多是锦上添花。关键发现：资产"轻重"是动态可转化的（如腾讯通过AI生态重塑壁垒），不应机械套用HALO选股。中游算力基础设施（数据中心、算力租赁）明显强于下游应用端。

### 2. 三分法资产配置实战模型
雪球黑金用户柴作军分享近30年投资经验，核心框架为"三分法"配置：
- **激进型**：股票70% / 债券15% / 商品15%
- **稳健型**：债券60% / 股票30% / 商品10%（适用于教育金等长期目标）
三类资产低相关性是关键——有纪律的比例约束比情绪判断更可靠。

### 3. 信用扩张方向跟踪法
中金刘刚提出：信用周期是解释2025年多类资产"反直觉同涨"和剧烈轮动的核心逻辑。投资应跟随信用扩张方向。2026年配置建议：AI + 分红板块搭配，进取型"先科技后周期"，稳健型构建低相关性组合。

### 4. 2025雪球嘉年华核心共识
- 方三文：中国资产A股港股仍有大量估值合理标的，2026年盈利概率较大
- 科技是第一驱动力，AI应用端2026年有望成为黑马
- 消费50板块估值低位，2026年有望修复
- 港股中长期投资逻辑顺畅，左侧布局机遇期
