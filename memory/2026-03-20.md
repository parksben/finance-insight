## Bug 修复（22:54 - 23:15）

### express.json() 与 http-proxy-middleware 冲突
- **问题**: 全局 `app.use(express.json())` 消费了 request body，proxy 转发时 body 为空，后端 pending
- **修复**: 移除全局 body parser，只在 `/auth/send-link` 路由上 inline 使用 `express.json()`

### secure cookie 不生效
- **问题**: Caddy 反代到 Node.js 是 HTTP，Express 不知道前端是 HTTPS，`secure: true` cookie 不设置
- **修复**: 加 `app.set('trust proxy', 1)` 让 Express 信任 X-Forwarded-Proto

### OAuth localhost 回调（23:10 - 23:15）
- **问题**: OAuth redirect_uri 硬编码 `http://localhost:8085`，远程浏览器无法回调
- **根因**: Google OAuth installed app 类型只允许 `http://localhost` redirect_uri，不能改域名
- **方案**: 环境变量 `OAUTH_CALLBACK_BASE` + auth-proxy OAuth relay 路由
  - 修改了 4 个文件: `gemini-oauth.js`, `iflow-oauth.js`, `codex-oauth.js`, `kiro-oauth.js`
  - 当 `OAUTH_CALLBACK_BASE` 设置时，redirect_uri 变为 `https://api.parksben.xyz/oauth-relay/:port`
  - auth-proxy 的 `/oauth-relay/:port` 路由把请求透传到 `127.0.0.1:PORT`
  - Location header 自动 rewrite 回域名路径
- **注意**: Express 5 (v5.2.1) 不支持 `app.all('/path/:param/*')` 通配符语法，用 `req.originalUrl` substring 代替

- auth middleware 白名单加了 `/api/login`（AIClient2API 原生密码登录，有自己的认证）
- 白名单加了 `/oauth-relay/`
