# 2026-03-18 Memory

## Niuma CLI Install Script Overhaul (04:00–05:07 CST)

PengAn asked to fix the niuma install script (`parksben/niuma-cli` repo, `install.sh`).

### Issues Fixed (chronological commits):
1. **File size display 0B** — `get_file_size` used unreliable HEAD/content-range methods. Fixed: cache GitHub API release JSON in `get_latest_version`, extract asset size via awk. (`ecb620f`)
2. **`curl | bash` pipe conflict** — curl calls inside script consumed stdin, truncating the script. Fixed: added `</dev/null` to all curl calls. Also fixed `format_size` awk syntax error on macOS (use `-v` flag). (`a55455b`)
3. **Download retry** — Added 3-attempt retry loop for connection resets. (`cac9d5a`)
4. **resolve_url HEAD hanging** — Removed `resolve_url()` and chunked download; simplified to `curl -L`. (`3e4a495`)
5. **Mirror fallback** — Added auto-fallback to GitHub mirrors (ghfast.top, gh-proxy.com, moeyy.xyz) + `GITHUB_MIRROR` env var support. (`e0cf0f0`)
6. **16-thread parallel** — Restored chunked download with 16 threads. (`51f17d3`)
7. **aria2c support** — Auto-detect/install aria2c for native multi-thread download; curl fallback with speed-limit abort. (`bc1b97c`)
8. **Resume downloads** — Persistent temp dir `~/.niuma/tmp/`, skip already-downloaded files (version+size check via `~/.niuma/.version`), aria2c `--continue=true`, curl `-C -`. (`b31d889`, `dad5538`)
9. **aria2c errorCode=13** — Clean orphaned partial files without `.aria2` control file. (`86bc711`, `0c5c423`)
10. **aria2c multi-source** — Fixed `--input-file` treating each URL as separate task; pass URLs as CLI args for true multi-source download. (`a0e0806`)

### Key Design Decisions:
- GitHub API JSON cached once (zero extra API calls for file sizes)
- aria2c preferred over curl chunked (handles redirects, resume, multi-source natively)
- All curl calls use `</dev/null` for `curl | bash` compatibility
- `~/.niuma/.version` tracks installed version for skip/upgrade logic
- Mirrors: direct → ghfast.top → gh-proxy.com → moeyy.xyz
