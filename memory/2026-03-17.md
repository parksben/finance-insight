## PengAn 产品需求：群聊共享记忆（重要）

**需求描述：** 在牛马产品的项目群聊中，所有 Agent 应该自动沉淀和积累对话记忆。当用户某天打开一个群聊，里面的 Agent 不能"断片"。

**这不是 OpenClaw 层面的事，而是牛马产品本身的功能需求：**
- 每个项目群聊应有自动记忆沉淀机制
- 群里的 Agent 应该共享项目上下文和历史决策
- 不能依赖单个 Agent 的 session 记忆（session 会过期/compaction）

**待实现方案（产品侧）：**
1. niuma-server 层面：每条消息持久化后，定期自动 summarize 聊天历史 → 写入 knowledge_docs
2. Agent 回复时，自动从 knowledge_docs 加载项目上下文（现有的 kbContext 机制可以扩展）
3. 可选：planner 角色定期做"项目记忆整理"，生成结构化摘要文档

- niuma-cli GitHub main 分支已有修复（commit `f3ea67e`, `b4e0808`）
