## 牛马（Niuma）项目 — 重大进展

### install.sh macOS 0B Bug 修复
- **现象：** macOS 上 `curl install.sh | bash` 显示 `共 0B (CLI 0B + Server 0B)`
- **根因：** `get_file_size` 通过 curl range request 获取 content-range，GitHub 302 到 S3 后 macOS curl 拿不到
- **修复：** 新增 GitHub API fallback（Method 3），直接从 release API 获取 asset size
- **Commit：** `c1eb7fe` pushed to `parksben/niuma-cli` main branch
- **验证命令：** `curl -fsSL "https://raw.githubusercontent.com/parksben/niuma-cli/main/install.sh?$(date +%s)" | bash`
