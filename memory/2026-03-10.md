## 澜投研发布脚本

- 脚本：`/usr/local/bin/publish-finance-report`，源文件 `workspace/scripts/publish-finance-report.sh`
- 用法：`publish-finance-report <YYYYMMDD>`
- 流程：复制报告 md → 生成 index.md → git push → 轮询 Actions → 成功后删本地文件
- 构建失败自动诊断：拉取 Actions 日志 → 识别常见错误 → 自动修复 → 重试一次
- 可修复的错误类型：package-lock.json 缺失、依赖冲突、Markdown 解析错误、config.mts 错误
- 超时/无法修复：本地文件保留，打印人工排查命令，exit 2
- 输出格式：`PAGE_URL=https://fin.parksben.xyz/daily/YYYYMMDD/`
