## machat v0.1.1 规划

### 待开发功能（已与 PengAn 确认）
1. **Agent 详情页**：头像/名字点击 → 弹出详情卡片（名称 + 能力说明）
2. **同角色多实例**：Agent 是模板，拉进群时可设置群内昵称 + 职责描述，同一 Agent 模板可在同一群加多次（如两个 Coder，分别负责前端/后端）
3. Planner 按群成员的职责描述来分配任务

### 产品设计共识
- Agent = 角色模板（Coder/Writer/Analyst/Planning…）
- 群成员 = Agent 实例，有独立昵称 + 职责
- 同一群可有多个相同角色的成员，各自职责不同
- Planner 感知每个成员的职责，按此分配任务
