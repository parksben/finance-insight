## WeCom Group Push Root Cause (Diagnosed 2026-03-13 ~11:30 CST)

### Problem
5 finance-evening cron jobs failed on 2026-03-12 21:00. 4 jobs completed successfully but push to WeCom group failed with `[object Object]` error.

### Root Cause (fully confirmed)
- Enterprise WeChat aibot `aibot_send_msg` (WebSocket proactive push) requires **session activation**: the bot can only proactively push to a chat if a user has recently sent a message TO the bot in that session.
- Errcode `93006` = session not activated / chatid not valid for proactive push
- SDK bug: `pending.reject(frame)` instead of `pending.reject(new Error(frame.errmsg))` causes `[object Object]` in logs
- Source: 企微官方文档 https://developer.work.weixin.qq.com/document/path/101463
