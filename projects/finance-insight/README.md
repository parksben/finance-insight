# 澜投研 — 长期理财研究专项

## 目标
- 持续学习头部理财博主的信息收集和投资分析方法论
- 沉淀形成一套「澜投研方法论模型」
- 定期产出前沿洞察报告
- 根据用户实际问题和情况给出有据可查的投资判断

## 目录结构
- `knowledge/` — 方法论知识库（从博主内容提炼，持续积累）
- `reports/` — 周报 & 专题洞察报告
- `prompts/` — 各定时任务使用的 prompt 模板

## 定时任务
| 任务 | 频率 | 时间 | 说明 |
|------|------|------|------|
| 每日学习 | 每天 | 09:00 CST | 抓取头部理财博主内容，提炼方法论，更新知识库 |
| 每日晚间 | 每天 | 21:00 CST | 根据当日市场大事件，给出简短投资判断 |
| 周报输出 | 每周一 | 10:00 CST | 基于知识库产出前沿洞察报告 |
